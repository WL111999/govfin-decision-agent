跑一次授信决策

输入企业名称或统一社会信用代码。系统会核验政务登记、采集社保与司法事实、 做跨域多跳推理，最后给出可追溯的结论。

样例数据里有四家企业：甲科技有限公司、乙贸易有限公司、丙建材有限公司、上海某钢材贸易有限公司。 其中乙贸易有连续三个月社保异常，能触发阈值判定，适合用来看完整链路。

知识库

把政策文件、制度汇编等非结构化材料放进知识库，智能体提问时就能检索到它们。 这里的向量化由本地模型完成——不需要任何 API key，材料也不出本机。

向量化服务用 BGE-small-zh 中文模型。之所以不用 DeepSeek： 它的 API 只提供对话端点，没有 embedding 端点（/v1/embeddings 返回 404）， 而把文本变成向量是检索的前提。

导入材料

把文件拖到下面的框里。系统会按类型自动送到该去的地方—— 你不需要先弄明白"该进哪一层"。

⬇
拖文件到这里，或点击选择
结构化数据 → 知识图谱　.json / .csv
工商登记、社保记录、行政处罚——变成图上可推理的事实
制度与文书 → 知识库　.txt / .pdf / .png / .jpg
监管条款、征信报告、判决书——回答"按规定该怎么办"时检索用

导入是追加语义，不会覆盖已有数据。同一份文件重复导入不会 让节点翻倍（节点按提及文本去重），但会新增边——需要干净重来时， 重建 Docker 卷即可。

在 Nexent 里用

Nexent 是智能体平台。govfin 的 10 个工具通过 MCP 协议接进去， 三份 Skill 工作流作为模板导入，智能体就能在 Nexent 界面里直接对话。

怎么用

1. 打开 Nexent → 资源仓库 → Agent 仓库
2. 点「导入」，选择桌面上的「跨域授信决策智能体.zip」
3. 完成后回到智能体列表，对它说：评估 乙贸易有限公司 的授信风险

导入包在 Nexent导入件\。用 zip 而不是 json —— zip 里带着三份工作流，一次装完。
